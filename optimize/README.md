# optimize/ フォルダ — 最適化スクリプト説明

戦略Bのパラメータ最適化ツール群です。
**実行頻度**: 月1回（月初に最新データで再実行）

---

## スクリプト一覧

### optimize_b.py — グリッドサーチ（推奨・メイン）

全パラメータ組み合わせを網羅的に評価します。GAより過学習リスクが低く、信頼性が高い。

```bash
python optimize_b.py          # 全Stage実行（30〜60分）
python optimize_b.py --stage 1  # グリッドサーチのみ（10分）
python optimize_b.py --stage 2  # ウォークフォワード検証のみ
```

**出力**:
- `out/opt_b_trades.csv` — 全トレードデータ（実行後S3に自動アップロード）
- `out/opt_b_stage1.csv` — グリッドサーチ結果
- `out/opt_b_stage2.csv` — ウォークフォワード結果
- `out/opt_b_report.txt` — 推奨パラメータレポート

---

### evolve_b.py — 遺伝的アルゴリズム（補助・参考）

グリッドサーチが見つけにくい複合条件を探索します。
結果はグリッドサーチと比較して採用判断してください。

```bash
python evolve_b.py                     # 20,000人・100世代（標準・約5分）
python evolve_b.py --pop 5000 --gen 50  # 軽量版（動作確認用・1分）
```

**過学習対策（2026-05-26 改善）**:
| 項目 | 変更前 | 変更後 | 理由 |
|---|---|---|---|
| Sharpeキャップ | 15.0 | 5.0 | 早期収束を防ぐ |
| 最小件数ペナルティ | /50 | /100 | 少件数の過大評価を防ぐ |
| MIN_SAMPLE | 5件 | 30件 | 信頼性の低い評価を除外 |
| condition | 遺伝子（自由） | NORMAL+STRONG固定 | グリッドサーチで最優秀と検証済み |

**出力**:
- `out/evolve_b_best.csv` — GA最良戦略（In/Out両方プラス）
- `out/evolve_b_history.csv` — 世代別Sharpe推移
- `out/evolve_b_report.txt` — サマリーレポート

---

### evolve.py — 戦略A用GA（参考）

戦略A（順張り）のパラメータ最適化。現在は参考用。

## パラメータ説明

### 戦略B の主なパラメータ（現在の採用値）

| パラメータ | 意味 | 採用値 | 更新日 | 根拠 |
|---|---|---|---|---|
| drop_lo / drop_hi | 対象下落率の帯 | -4〜-8% | — | scan_daily.py フィルタ |
| rb_min | RBスコア最低値 | 3以上 | — | グリッドサーチ |
| gap_max | 翌朝窓開け許容上限 | +2.0% | — | GA旧版 |
| **TP** | **利確目標** | **+3.2%** | **2026-05-26** | **GA(20000人×100世代)** |
| **SL** | **損切り** | **-6.2%** | **2026-05-26** | **GA(20000人×100世代)** |
| condition | 対象地合い | NORMAL+STRONG | — | グリッドサーチ |

### 最新GA実行結果（2026-05-26）
```
実行: python optimize/evolve_b.py --pop 20000 --gen 100
OOS通過: 153/200件（76.5%）

上位戦略:
  1位: drop-3.2〜-2.7% / RB>=3 / TP+1.6%/SL-6.5% → WR57.1% avg+0.113% Sharpe+1.056
  2位: drop-3.2〜-2.7% / RB>=2 / TP+3.2%/SL-6.2% → WR53.1% avg+0.130% Sharpe+1.054 ← 採用
  3位: drop-3.2〜-3.0% / RB>=2 / TP+4.6%/SL-7.0% → WR52.5% avg+0.141% Sharpe+1.054
```

**2位を採用した理由**: 最多件数(N=371)で統計的に最も安定。WR53%・avg+0.13%はOOS(未学習データ)での実績。

### RBスコアとは
Rebound（リバウンド）スコア。過去の下落からの回復パターンを点数化したもの。
- 高スコア（7〜9）: 過去に強く反発した実績あり
- 低スコア（1〜3）: 反発実績が少ない

## 実行順序

```
1. python optimize_b.py          ← グリッドサーチ（月1回）
2. python evolve_b.py            ← GA（グリッドサーチ後に比較用）
3. 結果を比較してTP/SLパラメータを closing_watch.py / market_watch.py に反映
```

S3自動アップロードにより、実行後すぐ他端末で `python download_db.py` で取得できます。
